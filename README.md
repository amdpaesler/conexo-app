# Conexo

Aplicativo mobile de comunicação escolar desenvolvido em React Native, Expo e TypeScript.

## Objetivo
Facilitar a comunicação entre responsáveis, professores e instituição de ensino por meio de mensagens, avisos e calendário escolar.
